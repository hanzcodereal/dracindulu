# dracindulu

Web nonton drama Asia bertema retro. Dibuat dengan Next.js 14 (App Router) dan TypeScript.

## Jalankan lokal

```
npm install
npm run dev
```

Buka http://localhost:3000

## Deploy ke Vercel

1. Upload proyek ini ke repo GitHub.
2. Di Vercel pilih Add New, Project, lalu import repo tersebut.
3. Framework terdeteksi otomatis sebagai Next.js. Tidak ada environment variable yang dibutuhkan.
4. Klik Deploy.

Atau lewat CLI:

```
npm i -g vercel
vercel --prod
```
